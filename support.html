Frequently Asked Questions

How can I add a website to favorites?

To add a website to favorites, follow these steps:

  1. Navigate to the website you want to add
  2. Tap the star icon in the top toolbar
  3. The website will be automatically added to your favorites list
  4. You can access favorites from the bottom navigation menu
How can I save a page for offline viewing?

To save a page for offline viewing:

  1. Open the page you want to save
  2. Tap the save icon in the toolbar
  3. Wait for the page to finish downloading
  4. The page will be available for offline viewing
How can I change app settings?

To access app settings:

  1. Tap the "Settings" tab in the bottom navigation menu
  2. You'll find all available customization options
  3. You can change theme, security settings, and more
  4. Changes are saved automatically
The app is not working properly, what should I do?

If you encounter issues with the app, try these solutions:

  1. Restart the app
  2. Make sure you have the latest version of the app
  3. Clear the app's cache
  4. Restart your device
  5. If the problem persists, contact us via email
Is the app safe for sensitive data?

Yes, the app is completely safe:

  • All data is encrypted using the latest encryption technologies
  • We don't collect or share your personal data
  • The app supports HTTPS for all connections
  • You can review our privacy policy for more details
How can I share a page with others?

To share a page:

  1. Open the page you want to share
  2. Tap the share icon in the toolbar
  3. Choose the app you want to share through
  4. Complete the sharing process
